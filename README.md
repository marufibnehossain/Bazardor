Project name: BazarDor

Description: BazarDor is a responsive web application for browsing the current prices of everyday products in Bangladesh.

Features:
1. View product prices and daily price changes.
2. Browse products by category.
3. Sort category products by price.
4. View detailed product and market-wise price information.
5. User registration and login with email/password.
6. Google and GitHub authentication.
7. Protected routes for authenticated users.
8. Update user profile information.
9. Responsive design for mobile, tablet, and desktop.
10. Loading states and 404 error pages.

Technologies Used
1. Next.js
2. TypeScript
3. Tailwind CSS
4. HeroUI
5. Better Auth
6. MongoDB
7. React Toastify
8. BazarDor API
